# accountsuspension.com

Website, CRM, client portal and CMS for AccountSuspension.com.

- **Website:** 87 static pages generated by Python. Every indexed URL keeps its exact slug.
- **AS Case Vault:** the private CRM and client portal (PHP 8.1+, MySQL or SQLite, libsodium encryption), adapted from DR Case Vault.
- **CMS:** blog posts, verified testimonials and redirects, managed inside the CRM and rendered on the website without a rebuild.

Deployment steps are in [crm/INSTALL.md](crm/INSTALL.md).

## What to upload

| Folder | Upload to |
|---|---|
| `dist/*` | `public_html/` (website, `portal/`, `api/`, `cms.php`, hidden `.htaccess` files) |
| `crm/ascrm/` | `domains/accountsuspension.com/ascrm/` (beside `public_html`, never inside it) |

## URL policy

All 21 indexed `/{platform}-reinstatement/` pages, plus `/services/`, `/blog/` and `/contact-us/`, keep their exact URLs. New platforms follow the same pattern. Old WordPress URLs that are not rebuilt should be added in the CRM under Website > Redirects (instant, no rebuild), or in `gen/redirects.csv` (written into `.htaccess` at build time).

## Build the website

```bash
pip install pillow fonttools brotli playwright
python3 gen/brand_assets.py      # only when the logo changes
python3 gen/platform_logos.py    # only when platforms change
python3 gen/build.py             # rebuilds dist/ and runs checks()
```

`checks()` fails the build on:
- em or en dashes, or emojis
- inline `style` attributes, or anything other than one external script per page (JSON-LD excepted)
- invalid JSON-LD, broken internal links or duplicate ids
- published email addresses while none is configured
- guarantee claims, placeholder text, or testimonials without a consent record

## Tests

```bash
export PW_CHROMIUM=/path/to/chrome            # optional: a preinstalled Chromium

# CRM + portal + CMS + website intake, end to end (fresh install each run)
qa/run_crm_e2e.sh /tmp/as-env 8091
# same suite on MySQL/MariaDB (database astest, user as/aspw by default)
AS_DB=mysql qa/run_crm_e2e.sh /tmp/as-env-my 8093

# Website: every page, link and button at 1440 and 390 px, plus axe-core accessibility
php -S 127.0.0.1:8092 -t /tmp/as-env/public_html qa/router.php &
python3 qa/site_audit.py http://127.0.0.1:8092
python3 qa/qa_matrix.py http://127.0.0.1:8092
```

The end-to-end suite has 23 groups, including:
- install and compulsory two-step sign-in
- website intake and encryption at rest
- public status check, lead screening and acceptance
- appeal and held-funds trackers
- client onboarding at 390 px and the engagement agreement gate
- chunked encrypted uploads, including spoof rejection
- isolation between clients, invoicing and data export
- key rotation, backup and restore, recovery codes and lockout, the Case Lead role, and CLI tools
- CMS posts, testimonials and redirects
- axe-core accessibility on CRM screens in light and dark

```
crm/website-api/         api/contact.php, api/config.php, cms.php (copied into dist/)
crm/INSTALL.md           deployment guide
dist/                    build output = public_html
qa/                      end-to-end suite, site audit, QA matrix, local router, axe-core
```
