# accountsuspension.com

Static rebuild of accountsuspension.com: 87 pages generated by Python, deployed to Hostinger `public_html`, with a PHP case intake that stores submissions encrypted outside the web root. Design system matches the Digital Repu v4 theme (navy `#00183F`, blue `#0054E4`, Plus Jakarta Sans and Inter, mega menus, CSS-only mobile nav).

## URL policy

Every URL indexed on the live site keeps its exact slug, including all 21 `/{platform}-reinstatement/` pages, `/services/`, `/blog/` and `/contact-us/`. New platforms follow the same flat `/{platform}-reinstatement/` pattern. Anything else that moved is listed in `gen/redirects.csv` and emitted as a 301 in `.htaccess`.

**Before go-live:** export the live WordPress sitemaps (`/sitemap_index.xml`, then `post-sitemap.xml` and `page-sitemap.xml`) and add any URL not present in `dist/sitemap.xml` to `gen/redirects.csv`. Existing blog post slugs could not be crawled from the build environment, so this step protects their rankings.

## Build

```bash
pip install pillow fonttools brotli playwright
python3 gen/brand_assets.py      # only when the logo changes
python3 gen/build.py             # wipes and rebuilds dist/, then runs checks()
```

`checks()` fails the build on: em or en dashes, emojis, inline `style` attributes, anything other than one external script per page (JSON-LD excepted), invalid JSON-LD, broken internal links, duplicate ids, published email addresses while none is configured, guarantee claims and placeholder text. It warns on titles over 62 characters and descriptions outside 110 to 165.

## QA

```bash
php -S 127.0.0.1:8080 -t dist &
PW_CHROMIUM=/path/to/chrome python3 qa/qa_matrix.py http://127.0.0.1:8080
```

Covers 360, 390, 768, 1024, 1280 and 1440 px: no horizontal overflow, no console errors, scroll reveal, mega menu on hover, mobile menu and accordion, services filter, Readiness Score, and an end-to-end intake submission through `api/contact.php`. The intake test needs `dist/api/config.php` with `127.0.0.1` in `ALLOWED_HOSTS`.

## Layout

```
gen/config.py              business facts (empty = not rendered)
gen/content_platforms.py   42 platform pages + 7 categories (legacy=True marks indexed URLs)
gen/content_services.py    9 services, method, ethics
gen/content_guides.py      12 blog guides (Article, HowTo, FAQPage schema)
gen/templates.py           shell, nav, mega menus, footer, JSON-LD
gen/components.py          reusable blocks
gen/build.py               page builders, sitemap, robots, llms.txt, .htaccess, checks
gen/brand_assets.py        logo SVGs (outlined glyphs), favicon, og.png
gen/redirects.csv          old -> new 301 map
static/                    CSS, JS, images, api/ (copied into dist/)
server-tools/read_cases.php  CLI decryptor for stored cases (never upload into public_html)
dist/                      build output = public_html
```

## Deploy to Hostinger

1. Back up the current WordPress site (files and database).
2. Upload the **contents** of `dist/` into `public_html` (include the hidden `.htaccess` files). Remove the WordPress files, keeping only what you have backed up.
3. On the server create `public_html/api/config.php` from `config.sample.php`. Generate secrets with `php -r 'echo base64_encode(random_bytes(32)), PHP_EOL;'`. Store `APP_KEY` offline: without it stored cases cannot be decrypted.
4. The intake writes to `as_data/` one level above `public_html` (created automatically, mode 0700). Confirm PHP 8.1+ with the sodium extension (Hostinger default).
5. Verify: `https://accountsuspension.com/api/config.php` returns 403; `http://` and `www.` redirect once to `https://accountsuspension.com/`; submit a test case and read it with `php server-tools/read_cases.php /path/to/public_html/api/config.php`.
6. In Google Search Console, submit `https://accountsuspension.com/sitemap.xml` and inspect the top legacy URLs.
